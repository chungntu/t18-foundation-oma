# T18 foundation — operational modal analysis

Code and results for the article *A Geometric Criterion for Sway and Rocking in Inclined
Pile Groups*. Ambient vibration identification of the pile-group foundation of wind
turbine **T18**, Dong Hai 1 wind farm, Tra Vinh, Vietnam, recorded **before and after
tower installation**.

The foundation is a 20.5 m diameter, 4 m thick circular pile cap on 34 PHC D1000 piles
in three rings, 30 of them raked at 5:1 or 7:1, with 12.34 m of each pile standing free
in water above a soil profile containing 13.4 m of very soft clay.

Every number quoted in the article is produced by one of the scripts in `src/`, run on
the measurement records.

---

## Layout

```
run_all.py        reruns every step below, in order
requirements.txt  Python packages
src/
  paths.py        single definition of all project paths (T18_DATA overrides the data path)
  oma/            identification: library, campaign runners, diagnostic analyses,
                  table generation
  model/          six-degree-of-freedom rigid-cap model, axial pile stiffness and
                  pile-group interaction
  figures/        figure generation
results/          identified modes (CSV), MAC matrices, stabilisation diagrams,
                  FDD plots, and the data behind the tables of the article
paper/
  paper.tex       the article (main text, Appendix A: rigid-cap model, Appendix B: fixity inversion)
  paper.pdf       compiled with pdflatex
  supplement.tex  supplementary material (record quality, N_eff threshold, full pole list,
                  processing settings, low-band search, setup-by-setup comparison,
                  sensitivity to the tower)
  supplement.pdf  compiled with pdflatex
  figures/        fig01 ... fig13 (no fig07) as PNG and vector PDF, regenerated by src/figures/
  references.bib  bibliography source
  make_references.py  writes the reference list into paper.tex from references.bib
dataset/
  README.md       description of the measurement records
  MANIFEST.txt    the 45 record files with SHA-256 checksums
```

## Reproducing the results

Requires Python 3 with the packages in `requirements.txt`. The measurement records (see
*Data* below) must be present under `data/Dien_gio_TraVinh/dot1` and `dot2`, or anywhere
else with `T18_DATA` pointing to the folder that holds `dot1/` and `dot2/`.

```bash
pip install -r requirements.txt
T18_DATA=/path/to/Dien_gio_TraVinh python run_all.py   # everything, about 10 minutes
```

`run_all.py` runs, in order:

```bash
python src/oma/run_dot1.py                # campaign 1: identification, 4 setups
python src/oma/run_dot2.py                # campaign 2: identification, 3 setups
python src/oma/participation.py           # effective channel count, both frequency bands
python src/oma/configuration_experiment.py# 2x2 factorial: covariance window vs high-pass
python src/oma/low_band_search.py         # search below 0.5 Hz for a tower mode
python src/oma/criterion_calibration.py   # N_eff threshold and sensitivity, by simulation
python src/oma/make_tables.py             # data behind the tables of the article
python src/oma/rotation_centre_test.py    # vertical/horizontal ratio, shape of the 1.052 Hz pole
python src/oma/segment_uncertainty.py     # scatter of the low-band poles between record thirds
python src/model/foundation_stiffness.py  # geometry, focal heights, forward axial stiffness
python src/model/rigid_cap_6dof.py        # 6-DOF rigid cap: modes, centres, L_eff inversion
python src/model/tower_sensitivity.py     # centre of rotation with a tower mode as an oscillator
python src/model/group_interaction.py     # group efficiency, forward axial pile stiffness
python src/figures/make_figures.py        # files fig01, fig02, fig11
python src/figures/make_figures_extra.py  # files fig03-06, fig08, fig09, fig12, fig13
python src/figures/fig_harmonics.py       # file fig10_configurations
```

The scripts in `src/model/` need no records and run on their own. A full run on
2026-10-06 reproduced every CSV in `results/` byte for byte (the model inputs were corrected from the design report on 2026-11-12: cap
volume 830 m3 and pile modulus 42.9 GPa, which changed the tables written by `src/model/`); the figures differ only in
font rendering between matplotlib installations.

`src/oma/oma_lib.py` holds the identification routines (pre-processing, SSI-COV, FDD,
MAC/MPC/MPD, harmonic screening); `src/oma/pipeline.py` is the processing chain shared by
both campaigns, so that the two are treated identically — a precondition for comparing
frequencies between them.

To rebuild the article after editing: `python paper/make_references.py`, then `pdflatex
paper.tex` (three passes) and `pdflatex supplement.tex` (two passes) in `paper/`. The
supplement refers to figures, tables and sections of the article by number, so check those
references when the numbering of the article changes.

## Main results

| | |
|---|---|
| Admitted band | 1.05–1.33 Hz; passes the three checks (N_eff above 1.25 in five of the six setups tested, present in every setup, damping 1.3–9.9%) |
| Mechanism | vertical/horizontal motion on the cap 0.08–0.16, against at most 0.09 for sway about the focal point and about 1 for rocking: rocking is excluded |
| Pile layout | focal heights 42.0 and 45.0 m; the axial rotational stiffness is least about 44.2 m, where it is 2% of its value about the pile heads |
| Rejected, local | 14–24 Hz: N_eff of 1.17 or less in five of seven setups, and three different bands in one campaign |
| Rejected, harmonic | 57–700 Hz: seven of twenty poles with damping 0.007–0.042%, within 0.2% of a multiple of 50 Hz |
| Change after tower installation | like-for-like setup means differ by −0.5 to −2.3%; a change smaller than about 5% cannot be resolved |
| Depth to fixity of the piles | 4.2–8.4 pile diameters below the seabed, inverted from the measured frequency with the cap mass and pile modulus of the design report; 2.3–3.0 from the single-pile rule of Davisson and Robinson |

## Data

The measurement records (2.4 GB; seven `.mat` files of about 470 MB are all the analysis
reads) are **not** included. They are openly available in Zenodo at https://doi.org/10.5281/zenodo.23177722;
`dataset/MANIFEST.txt` lists every file with its SHA-256 checksum so that a copy can be
verified. The foundation design drawings belong to the project owner and are not
redistributed; every quantity read from them is given in Table 1 and Figure 2 of the
article.
